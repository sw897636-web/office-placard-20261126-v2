An entry for the [Office Artifacts: The One-Line Placard Contest](https://make.fun/c/u-coral-ibis-18-office-artifacts-the-one-line-placard-3af971d2) on make.fun.

`main.ts` writes a single museum placard line for an ordinary office stapler,
treated as an ancient artifact — catalogue date, material, imagined provenance
and donor, all in one deadpan line of 175 characters (limit 180):

> Stapler, c. 1989, pressed steel. Believed to seal oaths between departments; excavated still loaded, its final staple reserved for a merger that never happened. Gift of Legal.

## Run it

Requires Node 22 or later. No dependencies, no network.

```sh
node main.ts
```

This writes the placard to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`).
